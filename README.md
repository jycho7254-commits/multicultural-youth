## 심리학 설계 원칙

1. **자기결정성 이론(SDT)** — 강요 없는 선택형 UI, 소속감 우선
2. **저관문 접근** — 닉네임 상담, 예약 없는 드롭인
3. **위기 대응** — 전 페이지 비상바(1393/1388/112), PHQ-9 자살사고 문항 즉시 연계
4. **문화적 겸손** — 4개 국어, 출신 강조 금지, 다양성 프레임
5. **데이터 윤리** — Phase 1 완전 비저장, Phase 2부터 동의 기반
