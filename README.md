└── 🤝 소개

운영툴 (admin.html)
├── 📋 게시판 — 비밀글 열람·답글(비밀답변 설정)·삭제

└── 🎵 음악 관리 — 카테고리별 편성·YT 미리듣기·신청곡 승인

├── eoullim_board (글+반응+운영자 답글+비밀답변 플래그)

## 🛡️ 심리·윤리 설계

- PHQ-9 문항 9 → 1393 크라이시스 즉시 노출 (다국어) · 전 페이지 비상바
- 마음체크: **개인정보 필수 입력 + 동의** (미동의 시 결과 미제공) — 개인정보 처리방침 모달
- 비밀글/비밀답변: 서버 뷰에서 마스킹 + 프론트 권한 분리 (작성자 owner_key만)
- 문항별 응답 저장 → 운영툴에서 위기 신호(자살사고 양성) 즉시 식별
